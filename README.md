# The Curious Case

An interactive autumn afternoon for CCT360, built with HTML, CSS and JavaScript.

**[Explore the website](https://sofmc50.github.io/the-curious-case/)**

Visit a coffee shop, collect photographs in the park and browse a bookshop in
any order. Your choices are saved in your browser. Collect three activity
memories to uncover a personal keepsake.

Open `index.html` to start, or use VS Code Live Server. There is no build step.
See [README.txt](README.txt) for the file guide and interaction details, and
[CREDITS.txt](CREDITS.txt) for the supplied design and image sources.
